# Home Taux

Redesign estático da página inicial da Taux, atualizado conforme o quadro `1679:1059` do [Figma](https://www.figma.com/design/pPqh8Es1LYd3O27OWMwrON/GS-Educa%C3%A7%C3%A3o?node-id=1679-1059). Os arquivos estão prontos para uma hospedagem estática ou integração ao site existente.

As fotos dos seis cards de soluções são ilustrativas. As imagens da hero desktop e mobile foram fornecidas para as revisões; o retrato da seção Sobre veio do Figma. O logotipo e as capas dos artigos vieram do site atual. Todas as imagens usadas na página estão salvas em AVIF.

Toda a página usa Archivo: peso 400 para textos, 500 para títulos e 600 para ações e destaques. A fonte é carregada pelo Google Fonts.

Para visualizar localmente, execute `python -m http.server 8000` nesta pasta e acesse `http://localhost:8000/`.

Antes da publicação, convém confirmar se o WhatsApp continua sendo o canal desejado. Os links institucionais e de artigos apontam para o site atual; o mapa busca o endereço informado no documento.
